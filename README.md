# Найдовший ланцюжок чисел зі збігом країв

## Завдання

Є список із 142 унікальних шестизначних чисел. Потрібно скласти найдовший ланцюжок, у якому кожне наступне число починається з тих двох цифр, якими закінчується попереднє. Кожне число можна використати не більше одного разу.

## Підхід

Числа зберігаються як **рядки**, а не `int`: так не губляться нулі на початку (наприклад, `007148`), а перші й останні дві цифри беруться зрізом.

Задачу зручно подати як пошук шляху в графі:
- вершина — двоцифровий «стик» (`00`–`99`);
- число — ребро з вершини «перші 2 цифри» у вершину «останні 2 цифри».

Ланцюжок чисел — це шлях по цих ребрах, у якому кожне ребро використано не більше одного разу.

## Алгоритм

1. Будую словник `by_prefix`: перші 2 цифри → числа, що з них починаються. Це дозволяє за один пошук знайти всі можливі продовження.
2. Запускаю пошук в глибину з відкатом із кожного числа як зі стартового.
3. На кожному кроці беру останні 2 цифри поточного числа, дивлюся кандидатів у `by_prefix`, пропускаю вже використані, додаю кандидата до поточного ланцюжка (`path`) і до множини `used`, рекурсивно йду далі, після повернення прибираю його з обох.
4. Якщо поточний ланцюжок довший за найкращий, зберігаю його копію (`best[:] = path`).
5. Результат збираю так: перше число повністю + кожне наступне без перших двох цифр.

## Складність

Задача про найдовший шлях без повторів ребер у загальному випадку експоненційна, тому часу в гіршому випадку потрібно багато. На 142 числах рішення працює за ~53 с (на моїй машині).

## Оптимізація

Початкова версія перевіряла «чи число вже використано» пошуком у списку (`nxt in path`), і працювала ~134 с. Заміна перевірки на множину `used` зменшила час до ~53 с (приблизно в 2,4 раза), бо пошук у множині не залежить від довжини ланцюжка.
